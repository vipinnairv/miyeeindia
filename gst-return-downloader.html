CHROME & EDGE EXTENSION

GST Return Downloader

Bulk download GSTR-1, GSTR-2B and GSTR-3B from the GST portal. Free, open source, and runs only in your browser.

Download ZIP (v1.2.0) User Guide (DOCX)

How to install

  1. Download the ZIP above and extract it to a folder you will keep.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and select the extracted miyeeindia-gst-return-downloader folder.
  4. Log in to gst.gov.in, open the Returns Dashboard, then click the extension icon to start.

You log in to the GST portal yourself. Your user ID, password and OTP are never seen or stored by the tool. The portal may change its layout at any time, which can stop the tool from working until it is updated.
